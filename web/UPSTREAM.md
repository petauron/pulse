# Upstream interface

Pulse Web is derived from [Tokinx/komari-theme-emerald](https://github.com/Tokinx/komari-theme-emerald):

- release: `v1.0.11`
- source commit: `b7baf4535939cfdda063d731943fc36e3ead4c51`
- license: MIT
- imported: 2026-09-03

Pulse retains Emerald's Vue component structure, responsive layouts, visual styling, theme behavior, cards, list, globe, and charts. Adaptations are limited to Pulse data transport and monitoring semantics, local runtime assets, truthful product attribution, and removal of functions that are not part of Pulse's monitoring scope.
