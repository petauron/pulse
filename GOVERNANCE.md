# Governance

Pulse is maintained by the Petauron organization.

Maintainers review changes based on correctness, security, resource usage, project scope, compatibility with the documented protocol, and long-term maintenance cost. Repository administrators make final release and security decisions.

Changes that add a new trust boundary, persistent data, privileged operation, external service, telemetry path, or remotely initiated behavior require an Issue and explicit maintainer agreement before implementation.
