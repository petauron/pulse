# Support

Use GitHub Issues for reproducible defects and focused feature proposals. Include the Pulse version, operating system and architecture, deployment method, relevant sanitized logs, and minimal reproduction steps.

Questions that contain credentials, private addresses, database contents, or other sensitive information must not be posted publicly. Security concerns belong in [private vulnerability reporting](https://github.com/petauron/pulse/security/advisories/new).

Pulse is maintained on a best-effort basis. The public Issue tracker is not an emergency support channel.
